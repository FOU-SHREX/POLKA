# POLKA 🎲

POLKA is a simple slack bot I build for Hack club stardance using JavaScript and Node.js.

This is my fouth project and my first Slack bot. I made it to learn how Slack bot work and how to keep them running 24/7

## Feature

- 🏓 /polka-ping - Check if POLKA is online.
- 🪙 /polka-coin - Flip a coin (Heads or Tails).
- 🎲 /polka-roll - Roll a dice (1-6).

## How to Run

1. Clone this repo.
2. Run 'npm install' to install the denpendencies.
3. Create a '.env' file and add your slack tokens.
4. Run 'node index.js' to start POLKA.

## Build with

- JavaScript
- Node.js
- Slack Bolt
- dotenv

## Hosting


POLKA is hosted on Hack Club Nest and runs 24/7 using systemd. It keeps running even when my laptop is turned off.
